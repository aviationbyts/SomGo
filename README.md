# SomGo 0.3.0 (prototype)
Mappen: public/ (de app + PWA-bestanden), api/ics.js (haalt je Somtoday-agendalink op).
Zet de INHOUD van deze map in een GitHub-repo en koppel die aan Vercel (gratis). Zie de stappen in de chat.
Je Somtoday-link zit niet in de code; elke gebruiker plakt zijn eigen link.
Accounts: vul public/config.js in met je Supabase-gegevens en voer setup.sql uit in Supabase (SQL Editor). Zonder config.js werkt SomGo zonder login (lokaal).
